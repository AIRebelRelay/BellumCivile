# S24 — контракт критичної поразки, чернетка без зміни коду мода

Актуальне доповнення до повних сорсів Bellum1.4.12.5. Усі попередні файли
S23C збережені побайтово. Версія не змінена: додані лише документи й перевірка
фактів сорсів, без нового виконання або зміни схем сейвів.

Контракт і карта викликів: `docs/cr-diplomacy/terminal-crisis/`.
- Добровільна угода та примусове врегулювання — різні підстави виконання.
- Історичні100 War Score не заміняють актуальної перевірки стану.
- Пропонується мінімум3 ігрові дні ПЛЮС реальний бюджет часу на повний цикл
  обох LLM: черга, TTFT, TPS/генерація, reasoning і раунди. Самих ігрових днів
  недостатньо; прискорення кампанії не повинно випереджати відповіді моделей.
  Це ПРОПОЗИЦІЯ, не реалізовані налаштування.
- Законні блокування, права гравця та невідомі часткові результати не обходяться
  таймаутом. Фактичний результат потребує Native receipt і перевірки наслідків.
- Чинний ordinary-intent journal не використовується для кризи потайки:
  потрібні окремі кризова персистентність, Native war epoch та шлюз виконання.

14 перевірок підтверджують поточні факти сорсів. Усі38 поведінкові сценарії
нової політики заплановані, НЕ виконані. Попередній успішний checkpoint13
збережений як доказ S23C; без змін коду мода його повторно не запускав.

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Tests\ForeignTerminalCrisis.Source.Tests.ps1
```

Очікувано `SOURCE FACTS PASS 14`. Це не ігровий тест політики.

У грі нічого замінювати або запускати зараз не потрібно. Windows-білд,
реальний serializer/save-load та активне керування дипломатією залишаються
відкритими перевірками. Поточний інвентар архіву —
`S24_PACKAGE_FILES_SHA256.json`; попередні інвентарі описують попередні етапи.
