# Bellum 1.4.12.5 — S23B, збережений журнал дипломатичних намірів

Актуальний опис цього ZIP. Попередні S23A документи й хеші залишені як історія;
інвентар початкового S23B — `S23B_PACKAGE_FILES_SHA256.json`.
Поточне тестове оновлення S23C описане в `README_TEST_REFRESH_UK.md`;
актуальний інвентар ZIP — `S23C_PACKAGE_FILES_SHA256.json`.

Додано журнал із власником та стабільним ID операції, прив’язкою до держав,
правителів, походження запиту й умов. Після load старі сесії відхиляються,
а незавершені записи доступні лише для повторної перевірки актуального світу.
Повторний запит не створює другого ID; скасований намір не відновлюється.

Підключено лише незалежне збереження журналу. Ігрових джерел запитів,
виконання договорів та ввімкненого LLM-режиму ще немає. Встановлювати в гру
зараз нічого не потрібно. Справжня серіалізація Bannerlord/save-load не перевірені.

Один накопичувальний запуск перевірок із кореня сорсів:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-ForeignDiplomacyCheckpoint.ps1
```

104 перевірки нового журналу, 8 перевірок схеми, 5 навмисних спотворень,
попередні 65 перевірок політики та сусідні фікстури пройшли тут окремо.
Тест пакування `ModuleLocalLogs` актуалізовано в S23C під дві DLL.
Історична помилка з відсутньою Naval-фікстурою усунена в тесті;
актуальні результати накопичувального запуску — у документації S23C.

Windows-білдер формує обидві DLL та повну структуру `Modules\BellumCivile`:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-CrBellumModuleWindows.ps1 -OutputRoot C:\CR_Builds\Bellum_14125_01 -GameFolder "F:\Steam\steamapps\common\Mount & Blade II Bannerlord" -WorkshopFolder "F:\Steam\steamapps\workshop\content\261550"
```

Цей білд із реальними DLL гри тут не виконаний. Журнал обмежений 128 записами
разом зі скасованими; старі ID не видаляються. Очищення/архівація та активне
керування дипломатією — ще відкриті задачі. Межі патча, докази й статуси:
`docs/verification/2026-11-18-foreign-journal/STAGE.md`.
